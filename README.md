# esperanza_system
Biometric Access Kiosk for Patient Record Management with Vital Sign and Queueing System Integration - Esperanza Health Center

## Notes on .bat files:
`start_kiosk_final.bat` – Launches backend, frontend, and Chrome
`setup_kiosk_startup.bat` – Creates a Windows Startup shortcut
`stop_kiosk.bat` – Force stop the system or ALT+F4

## How to run:
In terminal, 
   .\start_kiosk_final.bat (testing)
   .\setup_kiosk_startup.bat (Startup/EXE file)

## View Startup Folder
   Win+R
   Type `shell:startup`
